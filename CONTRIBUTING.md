# Contributing

Thank you for helping improve Notebook Digitizer.

1. Keep notebook data, photographs, `.env` files and OCR results out of commits.
2. Add or update tests for changes to the library format, filesystem service or transcription pipeline.
3. Run `npm test`, `npm run lint` and `npm run build` before opening a pull request.
4. Preserve Markdown as the authoritative record and keep Codex output behind schema validation and human review.

When reporting OCR quality, use synthetic or redistributable sample pages. Never upload another person's private notebook without permission.
